Live region/speed unlock over Web Bluetooth. Works in Chrome (Android/desktop) or Bluefy (iOS).

Read this first

Experimental - not yet verified on hardware. This reproduces what the official app does: it sets the scooter's region/SKU, which selects the speed cap. It does not flash firmware.

Persistent. The official app writes the region only once, at bind - a normal reconnect just reads it. So this change survives reopening the app. It reverts only if you unbind and rebind in the app, or manually pick a lower speed there.

Settings

Read status first to see the current max speed and region. Then Scan tries the region values, reads the resulting max speed after each, and fills the best one in here - press Unlock to apply it.

These write the speed directly, the same commands the official app's own Max-speed and Speed-limit screens use, without the region detour. For an XT5 the app itself allows up to 32 km/h; higher values depend on what the firmware accepts.

Advanced

The connection uses an auto-generated account id, so you normally leave this empty. Fill it only if the scooter refuses to connect (then use the owner's account id). Or paste a captured connect handshake to replay it.
